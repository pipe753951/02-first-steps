# #09. Archivos CSS

Es posible trabajar archivos CSS de la manera tradicional, e importarlos a un componente de React como si fuera una importación de JavaScript.

## CSS Modules

Es una forma de trabajar CSS en JSX donde se puede tratar la hoja de estilos como un objeto JavaScript. Para usarlo, el archivo CSS debe terminar con la extensión `.module.css`, y los elementos que la utilicen deben hacer referencia a los selectores como propiedades de objetos.
